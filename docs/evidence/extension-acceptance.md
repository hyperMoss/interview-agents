## 可用能力

| 用户操作 | 实现与验证 |
|---|---|
| 上传自己的简历 | PDF / DOCX / TXT / Markdown，本地提取、编辑预览、确认使用。真实合成文件验证成功，错误格式和过大文件拒绝。 |
| 配置联网搜索 | Tavily / Firecrawl v2，连接测试、加密密钥与有效期。逐场确认关键词，固定真实响应来源。HTTP 夹具验证两种协议，不自动发送简历、JD 或答案。 |
| 推算题量与环节 | 时长、回答长度、实习 / 校招 / 社招、一面 / 二面 / HR 参与计算，服务端规划。HR 最多 30 分钟，禁用编程。 |
| 动态重规划 | 每次作答后按服务端时间与最近 QA 耗时调整。手动调整总时间与回答长度，保留当前题、QA 和草稿，幂等键与版本限制竞争。 |
| 编程题 | 仅求职者技术岗且非 HR 面，按岗位和难度从固定题库选原题。无符合难度的题时开始前提示。代码与思路只供评估，不执行。 |
| 多维报告 | 技术能力 / 沟通表达 / 综合素质，逐题问题、原答案、原文依据、评价和改进，服务端汇总。技术维度可不适用。Markdown / JSON 导出。 |
| 题库管理 | 私有自建、编辑、删除和检索。LeetCode 公开 URL / JSON 批量导入、按地区与 slug 去重，严格 / 混合 / 灵活改编模式。面试固定题库快照。 |
| 继续和恢复 | 历史、页面刷新、模型故障保留作答、明确重试、取消和删除，归属隔离与既有租约回归通过。 |

## 审查与限制

原生 Sol 比较两种完整架构并选择会话聚合，采用题库快照、计划 revision 和重规划 requestId。Claude 子进程报告未登录，Grok CLI 缺失，未声称外部供应商审查通过。Astra 审查因工作区额度不足中断。独立 Sol 发现合法长标题、题库超额不可见、编程阶段重规划重开问答三个缺陷。均已修复，新增完整回归涵盖长标题、并发容量、整批回滚和阶段关闭。审查及修复结果保存在决策记录。

Luna 审核决策记录，发现浏览器失败仍写成等待中。已保留失败文件，并追加失败与后续通过记录。权限记录已经明确广泛授权遭自动审批拒绝，之后只授权四张新增表。没有遗留权限请求。[完整决策记录](extension-decisions.tsv) 与 [审查记录](extension-review.md)。

没有使用真实付费模型或 Tavily / Firecrawl 账号。协议、秘密边界与业务流程已验证；实际账号权限、网络、计费、模型评分质量未核验。搜索最多五条来源，返回资料视为不可信材料，不作为候选人经历证据。

文件上限 5 MB，PDF 仅前 20 页，不提供 OCR。DOCX 验证文本段落，不承诺复杂表格保真。提交简历上限 16000 字。无 RAG、语音或代码执行。

每个身份题库最多 500 题，包含内置题。超额新增明确拒绝，超额批量导入整批回滚，满额时已有题仍能去重。JSON 每批最多 100 题。严格模式按匹配库存缩减问答；非严格模式可生成题，所有面试最多 30 题。计时从首题取得开始，暂停或刷新不重置。到期后仍允许提交当前题并评分，不再展示新题。

身份为签名浏览器 Cookie，没有账号登录或跨设备同步。面试官演练复用当前问答流程，不提供实时听录或屏幕辅助。生产镜像组合、公开 HTTPS、全局成本限额和备份恢复未验收。

软件工厂保留已有 skill；本轮同步当前 spec、能力注册与生成文档。跨项目规则仍需要多个真实项目证据，不将本次单项目结果当作进化证明。
