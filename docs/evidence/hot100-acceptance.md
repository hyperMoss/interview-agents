日期为 2026-10-22。对应 REQ-017、REQ-018。本轮结果保存在本地，尚未提交或推送。

## 数据与功能

从 [官方 Hot 100 学习计划](https://leetcode.cn/studyplan/top-100-liked/) 的公开 `__NEXT_DATA__` 提取一百题、十七个专题。提取器只保存公开的题号、标题、slug、难度、专题与标签。没有采集完整题面、题解、账户或 Cookie。

快照为 [hot100.json](../../packages/interview/data/hot100.json)，日期 `2026-10-22`。元数据 SHA-256 为 `616fd666238a373eac20b7867fafa536e2a8906f420d412ff8d7b86623f2a93b`，仅覆盖题目元数据。独立审阅者也使用原始官方 HTML 重放提取器并确认相同哈希。

一百条原创目标、提示和可用模式关联存于 [学习卡](../../packages/interview/src/hot100-lessons.ts)。网页与命令行共同调用 [题单模块](../../packages/interview/src/hot100.ts)，不存在维护两份题单的要求。

入口为“算法跟打 → Hot 100 题单”。支持专题、难度、题号/标题/关键词、自评状态筛选，独立 Python 作答、思路、提示、下一道待练、作答导出和题库 JSON 导出。相关模式可带入已有跟打，未覆盖的题目明确显示无模板。原题与模板例题分别标识。

作答按题号保留在当前标签页。同版本草稿中的旧题号或失效条目单独过滤，其余有效作答保留；未知专题与选中题回退，并提示恢复情况。损坏 JSON、超大数据及存储不可用均有反馈。没有新增数据库表、模型调用或代码执行服务。

## 取舍与范围

Model the Domain 将官方元数据、原创学习卡和个人作答分开，使用题号关联。Type System Discipline 校验数据及持久化边界，拒绝未知条目并保留其余有效作答。Prove It Works 使用实际页面数据、真实题库导入、Python 旧模板测试和 Chrome 操作验收。

页面提供一百题的学习目标与提示，保留原站完整题目和判题入口。十二个既有通用模板不是一百份完整答案，未覆盖时不强行映射。复习进度是用户自评，代码不会在本页面运行。项目 skill 能引导后续具体解法讨论，但没有伪装成已接入网页的在线判题器或新的 AI 问答服务。
