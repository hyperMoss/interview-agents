## 设计取舍与限制

采用本功能内的模式目录与工作台，未引入全局练习框架。只读设计比较了这两种形态，当前只有一个消费者，选择更少共享状态的方案。

Model the Domain 将题面来源和跟打对象显式建模，避免模式切换覆盖草稿。Type System Discipline 用判别结构与 Zod 校验存储边界。Prove It Works 要求运行实际 Python 模板、真实题库与浏览器操作，未把构建代替交互验收。

关键词识别仍是启发式，不能判定唯一算法；模板仅解决各自例题。当前没有 Dijkstra、负权最短路或在线判题模板。文本一致也不证明用户理解或算法正确。草稿不跨设备同步，关闭标签页不保证保留。

本轮只同步本项目 spec 与生成上下文，没有修改全局 skill、安装外部 skill 或晋升跨项目经验。开发数据库、Redis 和应用保留运行，独立验收浏览器已关闭。
