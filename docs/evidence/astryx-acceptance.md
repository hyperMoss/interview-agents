# Astryx 迁移验收

对应 REQ-063；分工见 [迁移计划](../astryx-migration.md)。验收时间：2026-11-14 至 2026-11-15。

## 实施结果

- 原来引用 antd 的 24 个 TSX 文件改用真实 Astryx 组件；新增共享确认框组合，不保留 Ant Design 兼容层。
- 使用 `@astryxdesign/core@0.7.16`、Neutral 主题和预编译 CSS，按组件子路径导入。生产源码、CSS、package.json 和锁文件已无 antd 或 `.ant-` 引用。
- 保留受控输入、布尔开关、标签创建、上传、筛选、标签页和业务请求；补齐中文提示、必填字段名称、菜单方向键与 Home/End、异步确认失败重试和提交期间关闭保护。
- 步骤切换改为立即滚动，避免动画影响紧接着打开的选择器；移动菜单操作等待抽屉关闭，避免恢复焦点干扰编辑器输入。
- 先更新 spec，再重新生成能力上下文。没有修改 API/Worker 的业务写入边界或外部 BOSS 能力成熟度。
