# 验收计划

- TEST-REQ-001：建立练习后得到问题，模式标识与运行时一致。
- TEST-REQ-002：并发提交只有一个有效答案，伪造依据被拒绝。
- TEST-REQ-003：重启 Worker 后恢复；取消与迟到结果竞争时保持 cancelled。
- TEST-REQ-004：另一浏览器身份得到 404，删除后业务记录与运行时产物均清理。
- TEST-REQ-005：读取模型列表、测试并启用后完成 AI 面试；切换连接不改变旧面试；报告和浏览器存储无密钥。
- TEST-REQ-006：模型故障后恢复原作答，重复重试请求只生成一个有效轮次。
- TEST-REQ-007：刷新恢复当前标签页草稿；完成报告后导出 Markdown 或 JSON，并用相同资料重新练习。
- TEST-REQ-008：上传后填入可编辑预览；不支持、无文本或超限文件明确失败。
- TEST-REQ-009：实际调用配置的搜索服务，展示真实来源；简历与密钥不进入查询或报告。
- TEST-REQ-010：HR 时长不超过 30 分钟且没有编程题；已完成回答及当前题保持稳定。
- TEST-REQ-011：题库归属隔离，导入可重复；严格模式问答和编程题保留原题。
- TEST-REQ-012：逐题原文依据可核对，HR 技术能力为不适用，导出与页面一致。
- TEST-REQ-013：仅填岗位与 JD 可生成指定数量题目和答案要点；HR 与非技术岗只生成行为题；虚构 JD 依据或无效模型输出被拒绝，失败保留草稿。
- TEST-REQ-014：编辑后原文入库，重复保存不新增题目，越权与容量限制有效，失败整批回滚；严格练习呈现所选题面，刷新恢复标签页草稿。
- TEST-REQ-015：至少覆盖十二种常见模式；无匹配明确提示，负数子数组和与加权最短路提示适用限制；题库题面和套路示例独立展示，不将通用模板称为当前题的已验证答案。
- TEST-REQ-016：中文及 Unicode 字符、换行和缩进对照正确；切换模式、切换题目及刷新后可恢复，重置只清空当前对象；明确跟打一致不代表算法判题通过，不执行用户代码。
- TEST-REQ-017：官方元数据完整一百题并保留来源和快照日期；每题有原创学习摘要与提示，题号和 slug 唯一；不同题的代码与思路独立恢复，状态为用户自评；未覆盖模板明确提示，不能把跟打或自评称为判题通过。
- TEST-REQ-018：skill 能按题号和专题引导 Python 思路、提示、实现与复盘；工具实际查询并导出一百题，通过现有导入契约；不重复维护数据，不执行网页输入代码，不改变全局 skill 或经验库。
- TEST-REQ-019：关闭重开后恢复，损坏条目不影响其他草稿；冲突保留双方内容；备份默认排除个人资料且永不包含凭据，恢复失败保持原数据。
- TEST-REQ-020：前进后退与刷新回到原页面；资料可保存复制切换删除，校验定位字段；JD 备题与题库带入不丢输入。
- TEST-REQ-021：复习间隔为一三七十四天，需要再练安排次日；下一题遵循筛选和到期优先；编辑器可键盘退出，跟打不自动补全，不执行用户代码。
- TEST-REQ-022：超过五十场仍可找到记录，分页稳定且隔离归属；摘要不携带简历或答案；报告复习可回看依据；删除同步清理本机答案及关联复习，独立岗位档案保留。
- TEST-REQ-023：doctor 不输出配置密钥、不调用收费模型、不自动改环境；桌面与手机主流程可完成，失败保留输入并显式重试。
- TEST-REQ-024：GitHub Actions 实际完成完整回归，失败退出且上传测试结果与浏览器 trace；只使用合成资料及本地协议 fixture，不读取部署密钥或调用收费模型。
- TEST-REQ-025：任务与批次限制由服务端执行；页面刷新和前进后退恢复任务；不自动定时、不替雇主招聘，planned 设计不冒充已实现能力。
- TEST-REQ-026：保存原生筛选实际选中证据并核对返回字段；十五至二十五 K 合格，未知薪资需复核；硬条件先过滤，按简历与 JD 依据排序，AI 偏好仅用于同等匹配，不设任意匹配分数门槛。
- TEST-REQ-027：黑名单命中可追溯；未知不当作非外包；跨任务按稳定岗位标识去重，默认跳过已投递与发送结果未知待核对项，缺失稳定标识不得自动投递。
- TEST-REQ-028：匹配、备题与发送附件绑定同一版本及摘要；原文件可私有下载核对；校正文本不改写附件；不可替换为未核对的 BOSS 旧简历；删除取消引用任务并清理派生资料及本地文件，不影响其他身份。
- TEST-REQ-029：伪造引用被拒绝；缺失技能只作为准备目标；资料中的指令不能调用工具；明确确认简历与 JD 将发送到所选模型，业务快照、页面、导出及日志无模型密钥或浏览器凭据。
- TEST-REQ-030：旧版本、增删岗位、修改招呼语或简历均不能复用旧审批；无审批不发送；需对方同意时显示等待同意，不代聊或追答；点击或 HTTP 二百不能证明沟通或附件发送成功。
- TEST-REQ-031：不隐式导入日常浏览器凭据；只有显式打开且没有可用页或页为空白时才允许一次初始导航，会话检查不启动浏览器、不建页、不导航，并保留已打开的登录或验证页；重复打开与检查不产生额外导航；检测到安全页、明确频率或次数限制、主框架短时跳转循环时停止程序动作并锁定暂停，保留当前页供人工处理，只有显式会话检查观察到可用页才恢复，且不承诺网站脚本停止跳转；切换引擎或清除会话使既有审批的会话代际失效，数据库引擎取值约束随迁移更新；不绕过验证；会话凭据保存在本机私有路径并隔离归属。
- TEST-REQ-032：单岗结果未知只暂停该岗且不盲重试，其他已批准岗位可继续；登录或站点限制及连续广泛页面故障暂停整批；进程崩溃或租约交接不重发已完成或不确定的外部动作；真实浏览器所有权处验证并发与旧执行者隔离。
- TEST-REQ-033：项目追问同时引用简历与 JD，缺口不冒充履历；未选岗位可手动生成；旧 JD-only 接口保留；备题失败独立重试，不阻塞已批准投递、不触发重发；编辑后入库与严格模式题面一致且保留来源。
- TEST-REQ-034：合成站点通过真实浏览器客户端和 API、Worker、UI 验证原生筛选、审批冻结、附件身份、越权、去重、未知恢复、人工暂停及备题来源；不把 app.jobs 当招聘岗位；Agent 不写 app；未实际观察的 BOSS 登录和外发明确未验证，公开报告不含真实简历、凭据或会话资料。
- TEST-REQ-035：全部本地服务使用 SQLite 启动；面试与 BOSS 合成流程、并发去重、重启恢复、归属隔离及删除通过；不保留其他数据库的运行入口、依赖或部署配置，不清理用户数据。
- TEST-REQ-036：严格暂停时 API、Worker 和登录 CLI 不启动浏览器；手动模式的会话检查同步到应用但搜索与投递任务不被领取；检查不导航，真实外发保持禁用；离线验证不能声称解除账号风控。
- TEST-REQ-037：无简历和模型也能创建持久预览任务且不调用 Agent；开启 AI 才校验简历、模型与数据处理确认；预览不伪造匹配或招呼语，不直接批准外发；旧 AI 任务与数据保留，真实站点验证和投递确认独立完成。
- TEST-REQ-038：转换按 owner、revision 和 requestId 幂等校验，已取消或未完成预览不可转换；原岗位不重搜、不增加详情读取；无模型也可保存招呼语与审批合格岗位，不调用 Agent 或自动生成备题；未知雇佣关系、真实控件验证与外发模式门槛继续有效。
- TEST-REQ-039：先只读检查既有专用会话的站内简历；未读取到可辨认的简历或版本时保持未验证；真实站内简历投递仍需实现独立来源冻结和发送回执，页面打开或登录不等于已可发送；不绕过验证或复核未知雇佣关系。
- TEST-REQ-040：沟通方式与简历附件投递独立；未确认直招的岗位不因点击方式简化而放行；岗位标题不能充当公司名称，招聘主体须来自当前岗位公司侧栏或招聘者所属公司，不能取推荐岗位公司；点击和消息到达分别记录，未知结果不自动重试。
- TEST-REQ-041：仅浏览器页面导航重定向到已配置的本机入口，API 不重定向且 Origin 校验不放宽；既有身份数据不合并不删除；无合格岗位时默认展示待复核列表并说明阻塞；仅沟通无需简历或模型，批准冻结岗位，队列持久防重，站点自动招呼不追加消息或附件，未知不自动重试。
- TEST-REQ-042：启动时冻结失败且未点击的记录集合；每次提交前重新校验状态和版本，等待上一条确认后才提交下一条；已沟通、未知与取消不重发，失败、超时或退出页面停止后续提交；外部动作仍由 API 授权和 Worker 持久队列执行，页面控制器不宣称后台无人值守续跑。
- TEST-REQ-043：自定义词每项一至四十字符，去重并拒绝空白；与预设按或关系生成逐城市搜索计划，原样编码进搜索 URL；标题或 JD 字面命中自定义词保留原文依据，城市薪资直招规则仍有效；任务冻结并显示完整方向，旧任务未保存自定义字段时行为不变，不自动执行真实搜索或投递。
- TEST-REQ-044：兼容 cool-resume v3 与旧 v2 迁移，保留扩展字段；本机 SQLite 按浏览器身份隔离保存，修订号阻止旧页面覆盖；非法 JSON 保留编辑内容并定位错误；副本独立，删除不影响其他副本或已冻结的投递版本。
- TEST-REQ-045：姓名、联系方式、概要、技能、工作、项目与教育按配置顺序渲染，支持原有主题及排版；用户内容不能执行脚本或发起预览网络请求；生成 PDF 与投递附件一致，旧任务快照不变；不自动读取真实简历或发送资料到外部服务。
- TEST-REQ-046：桌面和手机均可打开菜单，当前入口可辨认，键盘可操作；刷新与前进后退恢复页面，现有深链接继续可用。
- TEST-REQ-047：桌面左侧常驻菜单，手机抽屉菜单，当前页及模块清晰；旧链接与前进后退兼容，面试历史可筛选和继续。
- TEST-REQ-048：复用隔离文件解析；保留完整提取文本和解析警告，可靠标签映射字段，不确定内容保留待整理，不虚构经历；失败保留输入，保存与副本沿用归属和修订约束。
- TEST-REQ-049：带入已保存简历文本快照与目标岗位，超限明确拒绝且不截断；后续简历修改不改变已开始的面试，已有面试草稿覆盖需确认。

检查真实终态、重试幂等、取消竞争、用户越权、生产禁用演示、真实 Provider 合同。类型检查与构建不能替代业务验收。
