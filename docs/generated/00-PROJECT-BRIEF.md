# 面试练习室

用户粘贴真实简历和岗位描述，完成有限轮次模拟面试并复盘反馈。

角色：candidate

不在范围：招聘自动筛选、声音克隆、实时语音面试、向量检索、不可信代码执行

## 需求与验收

### REQ-001

简历和岗位描述驱动个性化问题，演示模式明确标识。

验收：建立练习后得到问题，模式标识与运行时一致。

### REQ-002

每题只接收一次作答，反馈依据来自实际答案。

验收：并发提交只有一个有效答案，伪造依据被拒绝。

### REQ-003

浏览器断开不丢失任务，取消后不能提交迟到结果。

验收：重启 Worker 后恢复；取消与迟到结果竞争时保持 cancelled。

### REQ-004

用户只能查看自己的资料和面试历史，删除传播到派生数据。

验收：另一浏览器身份得到 404，删除后业务记录与运行时产物均清理。

### REQ-005

应用内启用自带模型连接，面试固定模型快照且密钥不进入业务记录。

验收：读取模型列表、测试并启用后完成 AI 面试；切换连接不改变旧面试；报告和浏览器存储无密钥。

### REQ-006

生成失败保留原作答，可显式选择连接重试或取消。

验收：模型故障后恢复原作答，重复重试请求只生成一个有效轮次。

### REQ-007

恢复资料和作答草稿，提供分维度复盘与可阅读的导出。

验收：刷新恢复当前标签页草稿；完成报告后导出 Markdown 或 JSON，并用相同资料重新练习。

### REQ-008

上传 PDF、DOCX 或文本简历，本地提取后校正再使用。

验收：上传后填入可编辑预览；不支持、无文本或超限文件明确失败。

### REQ-009

配置联网搜索连接并明确启用，搜索只外发岗位关键词。

验收：实际调用配置的搜索服务，展示真实来源；简历与密钥不进入查询或报告。

### REQ-010

按时长、回答长度、候选人级别及轮次规划环节，支持动态重规划。

验收：HR 时长不超过 30 分钟且没有编程题；已完成回答及当前题保持稳定。

### REQ-011

编程题仅求职者技术岗生效，自建和 LeetCode 导入题库支持严格、混合和灵活改编。

验收：题库归属隔离，导入可重复；严格模式问答和编程题保留原题。

### REQ-012

报告评估技术能力、沟通表达、综合素质，并提供结构化逐题 QA。

验收：逐题原文依据可核对，HR 技术能力为不适用，导出与页面一致。

### REQ-013

提供 JD 可在面试前生成可编辑题单，按级别与轮次匹配难度，区分岗位必备项和加分项并保留原文依据。

验收：仅填岗位与 JD 可生成指定数量题目和答案要点；HR 与非技术岗只生成行为题；虚构 JD 依据或无效模型输出被拒绝，失败保留草稿。

### REQ-014

预生成题目经用户选择后批量入库，可导出备题单并带入严格模式练习。

验收：编辑后原文入库，重复保存不新增题目，越权与容量限制有效，失败整批回滚；严格练习呈现所选题面，刷新恢复标签页草稿。

### REQ-015

算法练习按题面关键词推荐候选模式，展示匹配依据、适用边界、解题步骤与 Python 核心代码，可从编程题库带入题面。

验收：至少覆盖十二种常见模式；无匹配明确提示，负数子数组和与加权最短路提示适用限制；题库题面和套路示例独立展示，不将通用模板称为当前题的已验证答案。

### REQ-016

支持题面与核心代码照着跟打，逐行对照并定位首次差异，按练习对象恢复当前标签页草稿。

验收：中文及 Unicode 字符、换行和缩进对照正确；切换模式、切换题目及刷新后可恢复，重置只清空当前对象；明确跟打一致不代表算法判题通过，不执行用户代码。

### REQ-017

接入官方 LeetCode Hot 100 题单快照，按专题、难度、关键词与练习状态筛选，支持逐题独立写 Python、记录思路和复习状态，并可带入套路跟打。

验收：官方元数据完整一百题并保留来源和快照日期；每题有原创学习摘要与提示，题号和 slug 唯一；不同题的代码与思路独立恢复，状态为用户自评；未覆盖模板明确提示，不能把跟打或自评称为判题通过。

### REQ-018

提供项目内算法编程练习 skill 与确定性题单工具，共用 Hot 100 数据，可查询练习卡并导出兼容现有题库的 JSON。

验收：skill 能按题号和专题引导 Python 思路、提示、实现与复盘；工具实际查询并导出一百题，通过现有导入契约；不重复维护数据，不执行网页输入代码，不改变全局 skill 或经验库。

### REQ-019

本机长期保存资料、备题、答案与算法草稿，迁移旧标签页数据，提供保存状态、多标签页冲突保护及脱敏备份恢复。

验收：关闭重开后恢复，损坏条目不影响其他草稿；冲突保留双方内容；备份默认排除个人资料且永不包含凭据，恢复失败保持原数据。

### REQ-020

提供首页、可恢复导航、岗位资料档案与分步面试准备，设置后返回原任务。

验收：前进后退与刷新回到原页面；资料可保存复制切换删除，校验定位字段；JD 备题与题库带入不丢输入。

### REQ-021

算法练习提供 Python 编辑器、收藏、专题进度与按自评安排复习，套路跟打后可返回原题。

验收：复习间隔为一三七十四天，需要再练安排次日；下一题遵循筛选和到期优先；编辑器可键盘退出，跟打不自动补全，不执行用户代码。

### REQ-022

面试报告的重点关联 QA 并可加入复习清单，历史支持轻量分页搜索，危险操作确认影响范围。

验收：超过五十场仍可找到记录，分页稳定且隔离归属；摘要不携带简历或答案；报告复习可回看依据；删除同步清理本机答案及关联复习，独立岗位档案保留。

### REQ-023

启动诊断提供运行时与依赖连通性检查，页面统一加载、断网恢复和错误操作提示。

验收：doctor 不输出配置密钥、不调用收费模型、不自动改环境；桌面与手机主流程可完成，失败保留输入并显式重试。

### REQ-024

推送与合并请求自动验证构建、隔离数据库测试和浏览器主流程，并保留失败证据。

验收：GitHub Actions 实际完成完整回归，失败退出且上传测试结果与浏览器 trace；只使用合成资料及本地协议 fixture，不读取部署密钥或调用收费模型。
