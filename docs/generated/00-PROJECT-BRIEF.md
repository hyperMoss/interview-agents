# 面试练习室

用户粘贴真实简历和岗位描述，完成有限轮次模拟面试并复盘反馈。

角色：candidate

不在范围：招聘自动筛选、声音克隆、实时语音面试、向量检索、不可信代码执行

## 需求与验收

### REQ-001

简历和岗位描述驱动个性化问题，演示模式明确标识。

验收：建立练习后得到问题，模式标识与运行时一致。

### REQ-002

每题只接收一次作答，反馈依据来自实际答案。

验收：并发提交只有一个有效答案，伪造依据被拒绝。

### REQ-003

浏览器断开不丢失任务，取消后不能提交迟到结果。

验收：重启 Worker 后恢复；取消与迟到结果竞争时保持 cancelled。

### REQ-004

用户只能查看自己的资料和面试历史，删除传播到派生数据。

验收：另一浏览器身份得到 404，删除后业务记录与运行时产物均清理。

### REQ-005

应用内启用自带模型连接，面试固定模型快照且密钥不进入业务记录。

验收：读取模型列表、测试并启用后完成 AI 面试；切换连接不改变旧面试；报告和浏览器存储无密钥。

### REQ-006

生成失败保留原作答，可显式选择连接重试或取消。

验收：模型故障后恢复原作答，重复重试请求只生成一个有效轮次。

### REQ-007

恢复资料和作答草稿，提供分维度复盘与可阅读的导出。

验收：刷新恢复当前标签页草稿；完成报告后导出 Markdown 或 JSON，并用相同资料重新练习。

### REQ-008

上传 PDF、DOCX 或文本简历，本地提取后校正再使用。

验收：上传后填入可编辑预览；不支持、无文本或超限文件明确失败。

### REQ-009

配置联网搜索连接并明确启用，搜索只外发岗位关键词。

验收：实际调用配置的搜索服务，展示真实来源；简历与密钥不进入查询或报告。

### REQ-010

按时长、回答长度、候选人级别及轮次规划环节，支持动态重规划。

验收：HR 时长不超过 30 分钟且没有编程题；已完成回答及当前题保持稳定。

### REQ-011

编程题仅求职者技术岗生效，自建和 LeetCode 导入题库支持严格、混合和灵活改编。

验收：题库归属隔离，导入可重复；严格模式问答和编程题保留原题。

### REQ-012

报告评估技术能力、沟通表达、综合素质，并提供结构化逐题 QA。

验收：逐题原文依据可核对，HR 技术能力为不适用，导出与页面一致。
