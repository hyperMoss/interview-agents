# 完成当前面试应用

本轮优先完成面试产品，暂停软件工厂功能扩展。按当前 spec 完成文本面试验收；文件/RAG、搜索和语音不在本轮启用范围。

- [x] 应用内启用自带模型：草稿、模型列表、连接测试、生效配置、恢复默认。
- [x] 面试固定模型快照，自带密钥不进入业务记录、报告或日志。
- [x] 生成失败保留作答，支持显式重试及取消；旧结果仍受版本和租约保护。
- [x] 逐题依据、分维度反馈、汇总复盘和可阅读的报告导出。
- [x] 资料填写和作答草稿恢复，历史查找与继续练习。
- [x] 本地真实协议 fixture、数据库集成和浏览器完整闭环验收。

模型凭据由 Agent 服务持有，API 只做已授权转发。连接 ID 与公开模型描述可以进入任务快照，密钥使用独立加密存储及明确有效期。部署方默认密钥保持服务端配置。自定义接入和探测使用同一开关、地址规范化与出站策略；失败不切换内容接收方。

已有会话继续使用创建时的连接。配置变更影响新面试；失败恢复时，用户可明确选择当前连接重新执行原作答，不重复追加回答。报告保存每一题实际使用的模型来源。

验收结果：56 个单元与数据库/协议测试、4 个 Chrome 场景通过，类型检查与生产前端构建通过。测试服务与实际 Bun Agent 完成完整闭环；真实付费供应商账号与模型质量未验收。详见 [验收记录](evidence/acceptance.md)。
