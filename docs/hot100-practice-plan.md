# Hot 100 编程练习

先更新 REQ-017、REQ-018 并解析 spec，再实现。当前官方学习计划的页面内嵌公开 JSON 包含一百题、十七个专题；公开元数据由确定性脚本提取，保留来源和快照日期。页面中不采集题解、账户资料或完整题面。

题目元数据与本项目原创学习摘要分开维护，再由同一个领域模块装配练习卡。每题关联已覆盖的模式，未覆盖时显示无现成模板，保留独立作答和原题链接。不能把一个哈希表示例冒充一百题的答案。

界面在现有算法跟打下增加 Hot 100 题单。练习包含独立代码、思路、可展开提示、自评状态和下一题。题单进度与作答保留在当前标签页，按题号隔离；仅接受已知题号及有界文本。可选带入现有题面跟打，已有模式代码继续以模板例题标识。

项目 skill 放在 skills/algorithm-practice，通过 AGENTS.md 定向发现。命令行工具使用同一份题单查询、选题、导出兼容题库的 JSON，支持后续替换题单快照。

## 检查点

- Blocking first steps. 题单来源、一百题唯一性、数据结构与 spec 先确定。
- Independent workstreams. 元数据更新、界面和 skill 使用同一个数据模块；当前会话负责代码写入，最终只读审阅独立进行。
- Shared mutable state. 不增加服务端写入边界。独立作答与跟打草稿分开，只有显式使用已有导入操作才写私有题库。
- Smallest safe decomposition. 两份数据、一个装配/筛选模块、一个练习界面、一个可复跑工具与一份 skill；不新建在线判题服务。

验证一百题与官方快照一致、专题数量、筛选和下一题、自评及作答恢复、导出契约、命令行查询、skill 校验；真实浏览器验证选题、提示、独立作答、模式带入、重载及窄屏。
