# 个人长期练习体验完善

执行顺序是本机持久化、导航与资料、练习复盘、真实验收。需求对应 REQ-019 至 REQ-023。

完成条件是关闭重开可恢复草稿，设置往返不丢上下文，超过五十场历史可查，算法可复习并返回原题，备份恢复与冲突保护可重跑验证。保留现有业务归属与模型快照，不执行用户代码。

## 模块边界

- storage.ts 提供同步内存读取及异步 IndexedDB 保存，页面启动前初始化。每个对象有版本，跨标签页竞争不静默覆盖。
- 页面采用 hash 路由，资料档案与报告复习属于本机工作区。业务记录继续经 NestJS 读取写入。
- 历史采用轻量摘要与稳定游标。算法共用 Python 编辑器、题单与复习规则。

## 验收顺序

1. 验证迁移、重开、冲突、备份默认排除敏感数据以及恢复原子性。
2. 验证资料向导、导航、设置返回、历史分页与报告复习。
3. 验证算法编辑、复习日程、跟打与返回。
4. 运行构建、单元、隔离集成与浏览器回归，保存桌面和手机证据。

证据写入 docs/evidence/usability-acceptance.md，决策记录写入 docs/evidence/usability-decisions.tsv。真实收费供应商与固定协议 fixture 分别记录。
